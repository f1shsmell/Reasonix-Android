# 0.4.0

这一版把 Studio 工作台的变更审查搬进了手机：会话菜单里多了「工作台」，改动清单、每个文件的 diff、暂存、模型起草的提交和提交历史都在一个屏幕里完成，不用回到电脑前。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 新增

- **会话菜单多了「工作台」**：打开即是这份会话工作区的改动清单——按文件夹分组的文件树、每个文件的三态暂存勾选（已暂存/未暂存/部分暂存）、增删行数一目了然，点开文件就是逐行 diff。
- **直接在手机上提交**：勾选要提交的文件，模型会阅读暂存内容起草提交信息，改完确认即可；含疑似密钥时需要明确确认才会放开提交。仅本地提交，不会推送。
- **提交历史随查随看**：每个提交可以展开文件清单和任一文件的 diff；分支名、游离头、变更计数显示在工作台头部。
- **工作区文件浏览**：按目录浏览或搜索工作区文件，只读查看内容，带语法高亮；diff 里的行号点过去直接打开对应文件。

## 变更

- **刷新跟着 agent 走**：agent 每写完一个非只读操作、或电脑发来工作区变化通知，变更清单在 0.7 秒落定后自动更新；正在看的 diff 会原地保持旧内容，新内容到了再替换，不会闪「读取中」。
- **长列表分页**：变更超过 500 行时分批显示，尾部一行「还有 N 行未显示」，点一下多看 500 行。

## 修复

- **工作台首版评审修复**：变更超过 500 行时「显示更多」不再失效；从子目录发起的文件搜索点开不再是错误路径；切换仓库后打开的 diff 与提交历史不再串仓库；开发环境（StrictMode）下文件浏览与提交卡不再无响应。

## 已知限制

- 手机端没有「丢弃变更」和「推送」：这两类操作由电脑内核保留给桌面端，需要时请回电脑操作。
