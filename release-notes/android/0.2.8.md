# 0.2.8

这一版把上一版没修干净的地方补齐了：顶部色带的真正原因找到了，会话里同一条回答重复出现两遍的问题修掉了，输入框上方那行「已工作 N 秒」去掉了。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息和连接记录都会保留。

## 修复

- **顶部那条色带（上一版没修到根）**：上一版让状态栏颜色跟随页面，方向是对的，但只做到这一步。真正的原因是手机系统 WebView 从旧版本升到 140 以上之后，Capacitor 会把网页**铺到状态栏底下**而不是推到它下面，而状态栏本身仍是不透明纯色；页面顶部原本有一层径向渐变、恰好在最上边缘最亮，于是两个颜色相接就成了那道带。
  现在页面背景改成纯色，两个面在构造上就是同一个颜色，不再依赖 WebView 版本。浅色深色都干净。
- **同一条回答显示两遍**：当一条回答自己调用了工具时，工具卡片会插在回答的流式输出和最终定稿之间。原来的逻辑只看「最后一行」是不是还在流式，插了工具卡片之后就判定为不相关，于是把整段回答又追加了一遍——同一个问题下面出现两条一样的文字。
  现在会往回找仍在流式的那个回答气泡并就地定稿，不再重复。

## 变更

- **去掉输入框上方的「已工作 N 秒」**：这行计时对判断进度帮助不大，占地方又容易分心，已移除。运行状态仍由界面上其他提示表达。
