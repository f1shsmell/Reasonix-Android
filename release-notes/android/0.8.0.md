# 0.8.0

这一版让界面里的每一次变化都有来有去：弹层会退出、页面会淡入、列表里的行从它所属的位置展开、数字是滑过去而不是跳过去。同时也把几处「系统本来能判断，却让你来做」的地方收了回来。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 新增

- **统一的动效节奏**：出现、消失、移动、展开、加载、完成都有交代，全 App 同一套曲线和时长；按下会先有回应，再切换页面。
- **底部导航的选中标记会滑动**：三个入口之间是一个移动的指示条，不再是一块突然换位置的下划线。
- **再点当前标签回到顶部**：在「最近」或「项目」页往下翻之后，再点一次同一个标签即可回到列表顶部。

## 变更

- **派发后默认留在表单**：派发成功后在原处显示回执和「查看」，可以直接接着写下一个任务，不再自动跳回列表。想去哪里可以在「设置 → 偏好 → 派发后」里改（留在表单 / 回到最近 / 打开派发的会话）。
- **派发页只列一个项目时不再要求选择**：直接把项目名标出来，少一次没有意义的点击。
- **账号服务地址改为离开输入框即保存**，原来的「保存地址」按钮已移除；保存失败会退回已保存的地址并说明原因。
- **「忘记这个服务」需要再确认一次**，避免误触丢失云端连接和登录状态。
- **缓存命中率移到「上下文」面板**：它是一条读数，不该混在会话菜单的动作里。
- **账号页的登录按钮改为独立的主按钮**，暂不可用时能明显看出还不能点，并说明原因。

## 修复

- **错误提示不再显示内部错误码**：以前会出现「没派出去：client.offline」这类句子，现在只说发生了什么、可以怎么办。
- **深色纸面主题下用户气泡的光晕消失**：改用中性阴影，深色背景下不再出现一圈发光描边。
- **宽窗口下内容不再拉满整屏**：平板或桌面窗口里保持约 720px 的阅读列并居中，标题和箭头不再隔得很远。
- **减少动效设置被真正尊重**：系统开启「减少动态效果」后，动画与过渡会被压缩到几乎瞬时，弹层立即关闭，回到顶部改为直接跳。
- **去掉了几处没有可见效果的高开销模糊层**：顶部栏、底部导航和会话标题栏后面的内容并没有从它们底下滚过，模糊没有意义，却要在每一帧重新合成。

## 升级须知

- 版本号 0.7.2 → 0.8.0，versionCode 31 → 32，覆盖安装即可，无需重新配对。
- 会话行左侧原来的小方块装饰已移除；它没有标签也不可点击，删除不影响任何操作。
