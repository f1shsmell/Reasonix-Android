# 0.1.4

这一版把手机端的连接、通知和派任务串成了一条更完整的远程使用路径，并补上了配对失败时的直接回退。

> 从 0.1.3 正式版可直接覆盖安装；仍装着 debug 测试包的手机需要先卸载一次（签名不同），
> 卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 新增

- **首页派任务**：标题栏的派任务按钮可以直接选项目、写提示词并发出，不必先打开聊天；
  派发后仍会收到「需要你处理 / 完成」通知。
- **多会话通知**：前台服务会照看当前电脑上所有打开的会话，不再只盯当前聊天；每个被阻塞的
  会话有自己的通知和深链，常驻通知汇总运行中与待处理数量。
- **其他局域网电脑**：同时关注最多 4 台已配对电脑的待处理/运行状态，首页标明来源电脑；
  点卡片会先切换连接再打开会话。云端电脑仍只列出、不并行监控。
- **待处理卡片更完整**：显示来源电脑、等待/运行时长和未读标记，最久等待排前。
- **账号原生登录**：设置里直接用邮箱/密码登录，代理完成会话建立并自动批准设备码，
  不再等整个网页加载；网页登录仍保留为注册/找回密码入口。
- **语音输入**：输入区麦克风按钮调用系统识别器，转写追加到草稿。
- **快捷设置磁贴**：显示「N 待处理 · M 运行中」，点一下打开 App。
- **设置页滑动**：电脑 / 机器 / 偏好支持左右滑动，分段控件、列表和动效统一；
  完整支持减少动态效果。

## 变更

- 设置页标题和分段吸顶，连接状态卡压缩成一行，账号区进入首屏；手动地址折叠，
  扫码和粘贴仍是主路径。
- 锁屏上的提问/完成通知只显示通用文案，不再带会话标题和问题内容。
- 云端连接暂不支持后台通知，派任务时会明确提示；完成后回 App 查看。

## 修复

- **配对回退**：扫码后如果 Studio 的隐藏配对页没有落下 cookie（旧分享页、加载慢、端口不对），
  会继续尝试代理的 `POST /pair`；被浏览器用过的码不再报成 App 故障，失败的切换会尽量
  恢复上一台可用电脑。
- 状态读取失败时不再把空闲误判成结束，也不会因此停掉通知服务；其他电脑的轮询不再拖慢当前电脑。
- 首页待处理列表改为以 `/runtimes` 为准，不在会话树里的阻塞会话也能显示。
- 修复 Android 8–12L 上监控其他电脑时的路径解码崩溃。
- 退出登录同时注销 Cookie 和 Bearer 两个会话；云端派任务不再启动只能读局域网的 watcher。
- 配对码失效时提示「在电脑上换一个」；网络失败不再清掉还能重试的码。

## 已知限制

- 云端连接的后台通知仍未接入，关闭 App 后只有回到前台才能看到新状态。
- 其他电脑的并行监控只覆盖局域网；云端电脑只列出，需要先切过去。
- 多会话通知、磁贴、语音识别和配对页的运行时行为仍缺少真机逐项验证；
  这一版按编译、单元测试和 CI 构建发布。
