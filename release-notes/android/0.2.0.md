# 0.2.0

这一版重做了语音输入——按住说话、看着话被实时写成字;回答在生成过程中就边写边排版;
网络断掉也能被发现了。另有一批连接稳定性修复。

> 从 0.1.8 可直接覆盖安装。仍装着 debug 测试包的手机需要先卸载一次（签名不同），
> 卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 新增

- **按住说话**：输入框的麦克风键改为按住说话。按住时上方实时显示识别出的文字和
  音量波形，上滑取消，松手把听到的话填进输入框。不再弹出全屏系统对话框；
  第一次使用会请求麦克风权限。
- **回答边生成边排版**：回答在生成过程中就按 Markdown 渲染——代码高亮、列表、表格
  随着生成逐步成形，不再等整段生成完才突然"变脸"。
- **生成中的振动反馈**：回答还在生成时，手机会以轻微振动提示"还在干活"，
  口袋里也能感知；不会连续震动打扰。
- **Enter 键行为**：设置 → 外观新增「Enter 键」。默认 Enter 发送；接了实体键盘
  （折叠屏、平板）可以改成「换行」，Ctrl/⌘+Enter 发送。

## 变更

- **连接顺序由你排**：保存的电脑列表支持长按排序（比如"家里、公司、账号"），
  断线重连时按这个顺序把每一台都试一遍，不再只盯着最近用过的一台直到放弃；
  重新连上某台电脑也不会再把它自动顶到最前。

## 修复

- **断网能被发现**：电脑休眠、Wi-Fi 漫游或 NAT 超时后，链路看起来还在但消息全部
  干等超时。现在手机约一分钟内就能发现并自动重连，休眠期间的查询会自动补发。
- **打开设置不再弄丢连接**：打开设置页或切回前台，不再把正在使用的连接断掉重连；
  单次网络抖动会被容忍，连续失败才判定离线。
- **配对过期不再卡死**：配对过期后界面一直显示"已连接"但会话早已不可用。
  现在会明确显示失败并给出处理办法；顺带加固了本地代理，堵住一个可能被
  本地应用耗尽内存的问题。
- **暗色主题下 diff 更清晰**：工具输出里 diff 的增删行文字在暗色主题下接近
  不可见，现在两套主题各用各自的颜色。

## 已知限制

- 云端连接的后台通知仍未接入，关闭 App 后只有回到前台才能看到新状态。
- 其他电脑的并行监控只覆盖局域网；云端电脑只列出，需要先切过去。
