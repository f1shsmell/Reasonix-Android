# 0.3.3

这一版把会话的「精简」模式改成了 Qoder 手机版那种只看最终回答的形态，并收掉了一轮连接、缓存和原生层的稳定性问题。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 变更

- **精简模式只留最终回答**：每一段工作先收成一行「已处理 N 个操作」，下面只显示这一轮最终的消息；工具调用、中间说明和思考都折叠在这行里，点开仍能按时间线查看过程。标准、详尽两种模式保持不变。
- **另一台电脑的决策通知能落到正确的会话**：同一台电脑上同名的 pane、以及多台电脑上的同 id 会话，不会再串到别人的窗口；进程被系统回收后点通知，也会回到对应的会话，而不是没有反应。
- **连接判定更稳定**：网络检查与后台刷新共用顺序，晚到的旧结果不会覆盖新结果；中继地址格式损坏会立即报错，而不是重试半分钟；被切到后台的电脑列表，在下一次扫描时不会一直停在「未知」。

## 修复

- **冷启动的会话缓存真正生效**：之前磁盘缓存的命中判断在同一个任务里就开始、又立刻结束，缓存始终为空；现在会等所有键返回后再决定，冷启动能先画出上次的内容。
- **内核拒收的排队/插话不再吞掉输入**：收到 `rejected_*` 回执时保留草稿并说明原因，不再当作已发送而清空。
- **同一个提问/审批连点两下只提交一次**；被拒绝后按钮仍可重试。
- **图片预览与语音释放**：离开会话会回收未发送图片的预览 URL；语音还在启动时离开页面，也会放弃这次录音，不会让麦克风一直占用。
- **重命名时按输入法的回车确认候选词，不再提前提交半个标题**。
- **拖动排序后的第一次点按生效**，不需要点两下。
- **长按会话后返回键取消操作面板**，不会连带退出整个设置页。
- **「最新」按钮不再中断自己的滚动动画**。
- **计数格式**：999,500 以上显示为 1.0M，不再出现 1000k。
- **原生资源与安全**：代理响应限制在 16 MB（更大的文件请在系统浏览器打开），响应头会过滤换行注入；账号令牌和代理密钥改用系统 keystore 封装；WebView、FileProvider 和更新检查的资源范围收窄；云决策的 JS 传递会转义 U+2028/U+2029，老 WebView 不再整段失效。
