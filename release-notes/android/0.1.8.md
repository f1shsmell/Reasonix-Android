# 0.1.8

这一版重排了设置页，并大幅改善了长会话的打开和翻阅体验：长会话秒开、往上翻不再卡顿，
组网环境下连电脑不再慢，App 启动不再白屏，也可以主动断开连接了。

> 从 0.1.7 可直接覆盖安装。仍装着 debug 测试包的手机需要先卸载一次（签名不同），
> 卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 新增

- **长会话秒开**：重新打开会话时，上次看过/聊过的内容先从缓存画出来，历史读到了再校正；
  不再是空白屏干等。
- **长会话分段读取**：历史改为分页加载，打开会话只读最近一段，往回翻时按页补，
  特别长的会话不再整段等待或超时（关联 #38、#39）。
- **翻旧消息不卡**：会话渲染改为按窗口增长，向上翻时按需展开，不再一次性把几千条
  消息画进屏幕（关联 #37）。
- **设置页重新分组**：三个页签改为「电脑 / 账号 / 偏好」——连哪台电脑、账号与云端设备、
  这台手机自己的偏好，各归其位；「机器」状态并入电脑页，扫码时不再滚过账号区。
- **代理策略**：电脑页新增「网络」分组，显示当前连接与网络类型，并可选
  自动 / 绕过代理 / 跟随系统三种策略，VPN 组网下连不上电脑时有了手动兜底。
- **断开连接**：设置里可以主动离线了。断开后切后台、换网络都不会自动重连，
  重启 App 也保持离线；重连只需在已连接的电脑里点一行，或重新扫码。

## 修复

- **组网下扫码/连接慢**：使用蒲公英等组网时，手机的虚拟 IP 会被误判为局域网地址，
  连接被绑到不通的路由上，每次都要等十几秒超时。现在会先确认目标地址真的在
  Wi-Fi 子网里，组网流量改走 VPN 路由，扫码后秒连。
- **启动白屏**：断网或中继不通时，启动要等满一整轮连接超时才能进主界面。
  现在最多等 6 秒就会进入 App，连接恢复转入后台继续，连接条上能看到进度。
- **流式回复不重复**：网络恢复后，一条正在生成的回答不会再和它已完成的正文
  同屏画两遍（关联 #36）。
- **会话列表去重**：内核把某些消息折叠进会话后，列表不再把它们画成两条（关联 #40）。

## 已知限制

- 云端连接的后台通知仍未接入，关闭 App 后只有回到前台才能看到新状态。
- 其他电脑的并行监控只覆盖局域网；云端电脑只列出，需要先切过去。
