# 0.7.0

这一版把云端链路从轮询换成推送、让三档详略真正拉开差距，并修掉两个配对链路上的老毛病：审批不再等轮询，附件不再整块加密膨胀，扫码配对不再被旧凭据骗过。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 新增

- **云端链路的推送**：内核事件经密封通道内的多路复用流主动推送，审批、插话从最坏 3 秒的轮询间隔降到一次往返；空闲时不再每 3 秒一轮请求，省流量也省电。旧内核自动回退轮询，行为不损失。（关联 #196）
- **附件走密封大块通道**：图片等附件以二进制帧直传，不再整块 base64，线上体积约省三成，可中断续传，低内存手机更稳。（关联 #197）
- **云端通道可见**：连接行标出事件当前走的具体通道（事件推送 / 轮询回退），断流自愈窗口内聊天点变琥珀色并提示「云端恢复中…」；电脑推送来的待决策块即时清空，不再等 20 秒轮询。（关联 #198）
- **三档详略拉开差距**：标准 = 精简的结构之上保留中间说明，工具照旧折叠；精简 = 折叠成一行加最终回答，思考不点开就流式展示、点开看全部；详尽把每一步摊开。精简档的失败步骤保留 `!` 标记。（关联 #201）
- **精简档思考流式展示**：思考还在进行时，折叠行下方就是实时跟随的思考文本，点开仍是可滚动的全部内容；落定后回到「思考了 N 秒 · N 字」。（关联 #201）

## 变更

- **移除应用内 Studio 页**：用 WebView 跑桌面的完整界面必然落后桌面一个版本，这条入口整体移除；手机原生界面不受影响。（关联 #199）
- 连接页引用按钮文案、流式光标样式与 Studio 主题的表单语言对齐。（关联 #199）
- 构建链升级 AGP 9.4.1 / Gradle 9.9.1；依赖例行升级。（关联 #192、#195）

## 修复

- **配对以新凭据判定**：配过一次的手机旧凭据三十天内一直在，扫码页还没来得及花掉新码就会被误判配对成功，表现为「已连接但没有会话」；现在只有凭据真正变化才算配对。（关联 #200）
- **代理不再挑中空的凭据**：WebView 与内存两个 cookie jar 按名合并后随每个请求携带，不再因为挑中空的 jar 而被内核答「未配对」。（关联 #200）
- 引用按钮的文案不再形似双引号；带图的插话被拒时状态回到队列而不是暂停整条队列。（关联 #199、#201）

## 升级须知

- 云端推送与附件大块通道需要电脑端 Studio 同步升级到本日期之后的版本；对旧内核手机自动回退到轮询与 base64 附件，功能不损失。
