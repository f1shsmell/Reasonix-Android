# 0.7.1

这一版修掉 0.7.0 带进来的两个毛病：扫码一点就退回设置页，以及选好图片后一打字图片就没了。都是 0.7.0 的回归，0.6.0 没有。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 修复

- **扫码不再闪退**：0.7.0 换了构建链后，打包时误删了扫码解码所需的一部分 MLKit 类，扫描器一打开就在第一帧解码时报错并自行关闭。现在重新保留这些类，扫码恢复正常。（关联 #203）
- **打字不再清掉已选的图片**：选好图片或附件后，只要输入框内容一变，图片就会被当成「引用已被删除」而移除。现在输入文字不会再影响已选的图片和附件，只有点 × 或发送才会清掉。（关联 #203）

## 升级须知

- 只修 bug，没有接口或数据格式变化；从 0.7.0 覆盖安装即可，无需重新配对。
