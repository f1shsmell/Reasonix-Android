# 0.3.2

这一版收掉 0.3.1 遗留的两个操作问题。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 修复

- **选中文字一拖动就变黑**：旧版 Android WebView 不解析 `::selection` 里的 CSS 变量，半透明背景失效，系统就用默认墨色重绘选中的字。现在改用各主题固定的文字色和背景色（暖纸为棕底米白字，深蓝为蓝底白字），拖动选择柄时保持可读。
- **长按会话后点空白，会打开下面的会话**：关闭操作面板时补了一次性点击拦截。面板关闭后，同一次手势可能补发一个兼容性点击；这个点击会被吞掉，不会落到下面那行。新的按下手势会立即解除拦截，不影响随后正常点按。
