# 0.1.0

首个公开预览：一个不内置内核的 Android 客户端，连接桌面端 Reasonix Studio。

## 新增

- 局域网扫码 / 粘贴链接、Reasonix 账号云端中继；已连接电脑会保存，回到同一 Wi-Fi 优先局域网，
  离开后回落云端；连接状态可见，失败可重试。
- 首页「最近 / 项目」、搜索、待你处理、置顶、项目拖动排序。
- 对话：活动行、思考、执行命令、工具详情、「已处理 N 个操作」时间线、停止、排队 / 插话、
  模型与计划模式、图片与相机附件、任务清单、审批与结构化问答。
- 外观主题、工具批准姿势、连接与账号设置、前台服务保活与完成通知。
