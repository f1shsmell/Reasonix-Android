# 0.2.4

这一版修好了「局域网连接、退到后台却收不到 ask/完成通知」的问题，并把通知内容改成在手机通知栏里
真正能读全的形式。

> **0.2.3 用户可以直接在「设置 → 偏好 → 关于」检查并安装这一版**，这是第一个真正可用的应用内更新。
> 仍装着 0.2.2 的用户需要手动安装一次（0.2.2 的更新地址是错的）；debug 测试包仍需先卸载。

## 修复

- **局域网后台通知失效**：之前云端 watcher 可能在切到局域网后继续留在前台服务里，而它只通过
  WebView relay 轮询，永远看不到局域网的 ask 和完成事件。现在切换链路时会重新对齐 watcher；
  停止云端 watcher 也不会再误杀正在运行的局域网 watcher。常驻通知会正确显示「局域网 · …」，
  不再误报「后台提醒已开启」。
- **通知读不全**：标题固定为「需要你回答 / 批准」，会话名放到副标题；正文使用真正的问题内容，
  展开通知可看全文，不再用很短的 tab 标题冒充问题。

## 变更

- **默认只显示「去回答」**：ask/审批通知默认只有一个按钮，点击直达对应会话并落到最新内容。
- **通知里显示选项（默认关闭）**：设置 → 偏好新增开关。打开后，只有选项都很短（≤5 个汉字）、
  单选且不超过 3 项时才内联；长选项仍走「去回答」，避免被系统省略成看不懂的半句话。
- 审批的「允许 / 拒绝 / 本会话允许」在开关打开时恢复显示。

已知限制见 [docs/KNOWN_LIMITATIONS.md](../../docs/KNOWN_LIMITATIONS.md)。
