# 0.5.1

这一版把会话页补齐到 Studio 的样子：每条消息都有自己的操作，引用和附件不再占满输入框，长对话里也能一键回到开头或最新。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 新增

- **消息操作**：在你说的话下面能复制、编辑重发、回到这条之前；在回答下面能复制、引用、新建分支、重新生成。每轮结束会显示「✓ 已完成」和用时。
- **引用与附件卡片**：引用回答或添加图片、文件后，它们以小卡片停在输入框上方，不再把草稿塞成路径列表；点已选图片可以全屏预览，支持双指缩放和双击放大。
- **回到顶部**：记录右下角是上下两个按钮，向下到最新、向上回到会话开头，浮在内容上方而不是把内容压短。
- **缓存命中率**：标题栏 ⋯ 菜单里显示本会话的缓存命中率，以及命中、未命中的数量。

## 变更

- **掉线恢复更稳**：切换链路后的第一次读取偶发丢包，不再被当成「新链路不可用」；局域网探测改由本机代理批量完成，开着 VPN 时也能看见同一 Wi-Fi 的电脑；切换失败后的回滚最多等 6 秒，不会看着像卡住。
- **「绕过代理」只管系统 HTTP 代理**：私有地址在开着 VPN 时也不再交给系统代理；它不改变 socket 走哪张网卡。
- **Studio 页面跟着当前链路走**：手机离开 Wi-Fi 后不会拿旧局域网地址去开 Studio；云页面里的 `studio.reasonix.io`、`id.reasonix.io` 在应用内打开，不再被丢到浏览器。
- **登录只在应用内完成**：去掉了登录失败后改用系统浏览器的兜底，因为那样拿到的 cookie 应用读不到。
- **待办清单**：回合结束（包括取消）后会重新读取，全部完成的清单会收起，不再留在下一轮输入框上方。
- **分支**：沿用会话名，所以分支的分支不会都叫「分支」；运行中的回合也能对已结束的回合建分支。

## 修复

- **分支或改写失败时**会说明原因（这一轮还在跑、没有检查点、连不上电脑），不再点了没反应。
- **工作台**的暂存按钮和空状态改成 Studio 的说法，并补上当前分支的图标。
