# 0.2.3

这一版补上了附件、通知里的直接操作，修好了应用内更新的仓库地址和退出会话后消息重复的问题，
并让云端后台提醒在读不到会话时直接说明原因。

> **仍装着 0.2.2 的用户需要手动安装这一版一次。** 0.2.2 内置的更新地址把仓库名拼错了，检查更新
> 必然失败，这个错误无法从旧版内部修复。装上 0.2.3 后，「设置 → 偏好 → 关于」的更新入口恢复正常，
> 从下一版开始可以直接应用内升级。仍装着 debug 测试包的手机要先卸载一次（签名不同），卸载会清掉
> 配对信息和连接记录，安装后重新扫码即可。

## 新增

- **附件**：输入框旁的「+」新增相机、图片、文件和计划。文件支持日志、PDF 等，单个最多 20 MB；
  上传后会插入 `@` 引用并显示文件卡片，图片仍保留缩略图。
- **通知直接处理**：审批通知带有「允许 / 拒绝 / 本会话允许」；只有一个问题的单选题，最多三个选项
  可以直接在通知里点选。多选、自由输入和多问题表单仍保留「去回答」。
- **云端提醒诊断**：常驻通知会说明云端检查是否读到会话；「复制诊断信息」新增最近一次云端检查的
  结果、会话数和待处理数，便于定位提醒为什么没有出现。

## 修复

- **应用内更新地址**：修正 GitHub 仓库名，直连清单和两个镜像都指向真实 Release；发布流程会校验
  App、生成脚本和镜像使用同一个仓库名，避免再次发错。
- **幽灵消息**：退出会话再进入后，之前发送的消息不再重复出现。内核的 `turn_started` 不带原文，
  旧逻辑没有确认本地乐观气泡，缓存和 history 就各画了一次。
- **多问题 ask**：不再只提交第一个问题的答案；多问题表单统一走「去回答」，避免部分作答。
- **云端后台提醒**：不再因为页面可见标记跳过检查；读不到会话时常驻通知会显示「云端提醒暂时读不到
  会话」，而不是一直停在「已开启」。

## 变更

- 「关于」页新增「复制诊断信息」；更新行继续显示版本和更新说明。
- 原生写入通知操作时明确带上本机页面的 `Origin`，外来 `Origin` 仍会被代理拒绝。

## 已知限制

- 云端后台提醒依赖 App 进程和 WebView 存活；强行停止 App 或从最近任务划掉后不再提醒。
- 云端检查每 60 秒一轮，只监控当前连接的这台云端电脑；另一台云电脑仍只列出、不能并行监控。
- 如果常驻通知显示「云端提醒暂时读不到会话」，请复制诊断信息反馈；最近一次检查的错误码会说明
  是后台请求超时、relay 离线还是返回了空列表。
- 更新检查有 6 小时缓存；想立即重查，点「重新检查」。
