# 0.1.5

这一版把首页图标换成桌面端同一套线性图标，并修好了列表滚动、会话操作和局域网连接在 VPN 下的几个问题。

> 从 0.1.4 正式版可直接覆盖安装。仍装着 debug 测试包的手机需要先卸载一次（签名不同），
> 卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 变更

- **首页图标与桌面端统一**：设置、派任务、新建会话、刷新和连接条改用 Studio 同款线性图标；
  设置入口从齿轮换成滑杆图标，一眼能认出是设置。
- **App 图标更新**：使用官方猫标，并提供深色与单色自适应图标，适配不同厂商的图标遮罩。
- README 首页预览按新界面重新渲染。

## 修复

- **列表滚动**：修复部分设备上首页和项目页列表被压缩、无法正常滚动的问题。
- **会话操作**：项目详情里的会话长按操作恢复，重命名、删除和置顶回到正常入口。
- **拖拽动效**：项目排序时恢复抬起的浮层和相邻行让位效果。
- **VPN 下的局域网连接**：检测到 VPN 或系统 HTTP 代理时，优先用非 VPN 的 Wi-Fi / 以太网直连局域网电脑；
  仍然失败时，连接页会说明可能与 VPN 有关，而不是只报连接超时。

## 已知限制

- 云端连接的后台通知仍未接入，关闭 App 后只有回到前台才能看到新状态。
- 其他电脑的并行监控只覆盖局域网；云端电脑只列出，需要先切过去。
