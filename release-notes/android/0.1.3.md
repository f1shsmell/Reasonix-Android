# 0.1.3

第一次用固定密钥签名的正式版本。连接、通知和会话阅读都做了较大改进。

> **安装提示**：之前装过 0.1.x 测试包（debug 签名）的手机，需要先卸载旧版再安装本版，
> 因为两者签名不同，Android 不允许直接覆盖。卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 新增

- **连接页状态动画**：连接时产品标记逐笔描出，并显示「查找电脑 → 切换连接 → 读取会话」；
  连上后停在对应颜色，失败时原地说明原因。
- **云端身份指纹**：第一次通过云端连接一台电脑时显示它的身份指纹并请你确认；之后每次连接
  （包括自动重连）都核对，钥匙变了就拒绝，而不是悄悄连上另一台电脑。
- **会话详略**：精简只留结论和一行操作摘要，标准在运行中逐条展开，详尽始终展开每一步。
- **机器页（只读）**：最近 30 天用量与成本、上下文占用、工具与权限边界、桌面端版本。
  这些是桌面端的决定，手机只解释、不修改。
- **检查点与回退**：从聊天「…」菜单回到任意一轮之前的快照。先看恢复计划（文件数、覆盖范围、
  快照外改动），确认后才执行；只恢复编辑工具写过的文件。
- **首页实时状态**：分开列出「待你处理」和「正在运行」，可见时每 20 秒刷新，回前台也会重读。
- **后台运行设置**：直接查看通知权限和电池优化状态，点一行跳到对应的系统设置。

## 变更

- 设置分成 **电脑 / 机器 / 偏好** 三页，不再是一条很长的列表。
- 工具批准从全局设置移到聊天的「…」菜单——它只对当前会话生效。
- 常驻通知写明当前走局域网还是云端；连续几次读不到会话时改为「连接中断，正在重试…」。
- 不同会话的通知使用各自的编号和深链，不再互相覆盖或点开错会话。
- 锁屏保活增加 Wi-Fi 锁，长回合会续期 CPU 唤醒锁。
- 正式包改为 R8 + 固定密钥签名；聊天页按需加载，安装包更小、首屏更快。

## 修复

- 中文输入法拼音选词时按回车不再误发送。
- 提交请求断在半路时提示「先刷新确认」，不再给一键重试，避免同一轮跑两次。
- 草稿按会话路径保存，桌面关闭 pane 再打开不再丢。
- 返回键先关闭当前弹层，不再从模型/附件/检查点页面直接退出。
- 连续使用后代理线程泄漏、SSE 重连越来越慢的问题。
- 用户消息气泡对比度不足；键盘弹出时输入区的调整方式。
- 通知点击可能打开错误会话的问题。
