# 0.1.6

这一版修好了网络不好时重进会话的等待和误报，让状态栏和手势条不再压住内容，
并给通知换上了 App 自己的图标。

> 从 0.1.5 正式版可直接覆盖安装。仍装着 debug 测试包的手机需要先卸载一次（签名不同），
> 卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 新增

- **排队消息面板**：一轮还在跑的时候，可以从输入框上方的提示或会话头部的菜单打开队列，
  看到排在这轮后面的消息，而不必等这一轮结束。

## 变更

- **App 图标**：猫形 R 缩小到自适应图标的可见区域（原来几乎顶到边，圆形遮罩下会超出安全圆），
  底色从纯黑提亮为 App 深色主题的卡片色，在深色壁纸上终于有了边界。
- **通知图标**：通知横幅、状态栏、锁屏和快捷设置磁贴统一使用 App 自己的 R，
  替换掉原来系统自带的 ⓘ 和循环箭头。

## 修复

- **网络不好时重进会话**：会话内容会立刻从本地缓存画出来，不再先显示「这个会话已经关掉了」
  再等网络。缓存也不再排在连接请求后面，并且改用会话路径做标识——之前每次打开都是新的键，
  冷启动时缓存实际上从未命中。
- **状态栏压住内容**：部分 Android WebView 把安全区高度报成 0，导致首页标题顶进状态栏、
  输入框贴着手势条、底部弹层失去留白。现在改用系统实测的数值兜底。
- **部分设备上文字和气泡消失**：Android 12 自带较旧的 WebView，不支持较新的颜色混合语法，
  用户气泡会变成透明，看起来像「我的消息不见了」。已为这些设备补上回退配色。
- **局域网连接在 VPN 下失败**：检测到 VPN 或系统 HTTP 代理时，优先用非 VPN 的网络直连电脑；
  仍然失败时，连接页会说明可能与 VPN 有关，而不是只报连接超时。
- **重复的提问卡片**：连接不稳定时同一个提问会收到多份副本，界面上叠出三张一模一样的卡片。
  现在按 id 合并成一张。

## 已知限制

- 云端连接的后台通知仍未接入，关闭 App 后只有回到前台才能看到新状态。
- 其他电脑的并行监控只覆盖局域网；云端电脑只列出，需要先切过去。
- 网络很慢时虽然会显示「已缓存 N 条」，但消息正文仍要等连接恢复才画出来。
