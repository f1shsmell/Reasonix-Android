# 0.2.1

这一版让同一台电脑的两种连接被认成同一台：云端和局域网记录合并成一行，回家连上
Wi-Fi 会自动切到局域网直连。另修复了 VPN 下连不上局域网、长按语音键弹出复制，
并把设置页收紧、主页图标换新。

> 从 0.2.0 可直接覆盖安装。仍装着 debug 测试包的手机需要先卸载一次（签名不同），
> 卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 新增

- **同一台电脑只显示一行**：云端连接和局域网连接会按电脑名识别为同一台，不再在
  连接列表里出现两行；点一行即可在可用线路间重连。
- **回家自动切到局域网**：正在用云端连接时，回到同一个 Wi-Fi 并确认是同一台电脑后，
  会自动改走局域网直连；切换失败会恢复云端，不打断当前会话。

## 变更

- **设置页更紧凑**：标题、分组和行文字统一字号；去掉了“连接、账号与偏好”副标题和
  设置内的说明文案，通知、电池、远程访问等状态改到右侧显示。
- **主页图标更新**：设置、派任务、新建会话、刷新换成更清晰的齿轮、纸飞机、撰写和
  双弧箭头图标。

## 修复

- **VPN 下连不上局域网**：开启 VPN 时，代理策略“自动/绕过代理”会为同一 Wi-Fi 下的
  电脑走 Wi-Fi 直连，不再被 VPN 全部带走；蒲公英等 mesh VPN 的地址仍走隧道。
- **长按语音键弹出复制**：麦克风键改为图标，长按只用于说话，不再触发文本选择与
  复制菜单；上滑取消保持不变。

## 已知限制

- 云端连接的后台通知仍未接入，关闭 App 后只有回到前台才能看到新状态。
- 其他电脑的并行监控只覆盖局域网；云端电脑只列出，需要先切过去。
