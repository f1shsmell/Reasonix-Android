# 0.7.2

这一版把扫码真正修好了。0.7.1 只修好了一半：扫描器不再闪退，但第一帧解码仍然失败，报「There was an error scanning the barcode with ML Kit」。0.7.2 补上了其余被误删的 ML Kit 类。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 修复

- **扫码解码恢复正常**：0.7.1 漏保留了一部分扫码初始化要用到的 ML Kit 类（`BarcodeScanning`、`InputImage` 等），扫描器能打开、但每帧解码都报错。现在这些类连同它们依赖的实现一起保留，扫码可以正常识别二维码。（关联 #205）
- 上一版的两个修复不变：扫码不再一点就退回设置页；输入框打字不会再清掉已选的图片。（关联 #203）

## 升级须知

- 只修 bug，没有接口或数据格式变化；从 0.7.0 / 0.7.1 覆盖安装即可，无需重新配对。
