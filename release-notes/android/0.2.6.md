# 0.2.6

这一版把发出去的任务、连接和界面细节一起收拾了一遍：派出去的任务立刻能在首页看到，
聊天输入框的 Enter 默认改成换行，状态栏和内容区之间不再有那道色带。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息和连接记录都会保留。

## 新增

- **聊天字号可调**：设置 → 偏好 → 字号，四档（小 / 标准 / 大 / 特大）。正文、标题和代码块
  一起放大，时间戳这类界面文字保持原样。
- **会话可以换项目、可以归档**：会话菜单里新增「移动到项目」和「归档」；项目页能看到该项目
  的归档会话，也能一键恢复。
- **在应用内打开完整 Studio**：连接条旁边新增入口，用手机直接打开这台电脑的完整网页版，
  不用再跳出 App。
- **聊天顶部会显示这一轮已经跑了多久**，回答结束时标出落地时间；模型 chip 会一起显示
  思考强度（最高 / 高 / 中 / 低 / 自动）。

## 变更

- **Enter 默认换行**：Enter 换行，Ctrl/⌘+Enter 发送。手机键盘上的回车图标也会跟着变。
  想回到「Enter 直接发送」，在设置 → 偏好 → Enter 键里选「发送」。
- **设置页精简**：「电脑」页去掉了只读的「这台电脑」区块（最近 30 天用量、上下文、工具等），
  这些信息在手机上不能操作，只是复述桌面端；上下文用量已经在会话里自己的入口中。
- 聊天头部的标题显示得更完整，长标题不再被两侧按钮挤掉。

## 修复

- **派发任务后首页看不到**：在首页「派任务」发出后，现在会立刻出现在「正在运行」里，
  不用再等半分钟。
- **状态栏和内容之间有分割**：深色和浅色模式下都修好了，状态栏会跟着页面实际使用的背景色，
  图标也会跟着变深或变浅。
- **「通知里显示选项」出现两次**：震动区块里重复的那一个已删除，只保留通知区块里的。
- **云端连接拖慢局域网探测**：云端握手现在和局域网探测同时开始，不再等探测扫完；
  某个地址在探测时没应答、稍后又起来了，也会在退避前回头再探一次。
- **配对页面不回话时一直转圈**：「扫码连接」现在会在 20 秒后给出明确失败，不再无限等待。
- **上下文压缩的状态提示**：被拒绝折叠（没有可折叠内容）和正忙（这一轮还在跑）现在分开提示，
  不再混为一谈。

## 已知限制

- 从 0.2.5 之前就装着的手机，如果当时在设置里主动选过「Enter 直接发送」，升级后会回到新的
  默认值「换行」。旧版本对默认值的处理无法区分「主动选过」和「从没选过」，所以没有做迁移；
  需要的话在设置里再选一次即可。
- 「弹窗提醒」和「常驻通知」由 Android 通知频道控制，频道重要性在创建时固定；开关通过切换
  频道实现。更多见[已知限制](../../docs/KNOWN_LIMITATIONS.md)。
