# 0.1.7

修好 0.1.6 里的两个问题：通知图标没有生效，以及旧的长会话读不到历史。

> 从 0.1.6 可直接覆盖安装。仍装着 debug 测试包的手机需要先卸载一次（签名不同），
> 卸载会清掉配对信息和连接记录，安装后重新扫码即可。

## 修复

- **通知图标**：0.1.6 换上 App 自己的 R 之后，状态栏和通知横幅在真机上仍显示旧图标。
  已修正图标的绘制方式，现在能正常显示。
- **旧的长会话读不到历史**：打开以前的长会话时显示「没读到历史」，而新会话和正在运行的会话都正常。
  原因是读取超时太短，会话越大越容易触发。已放宽超时，长会话现在能读出来；
  失败时也会说明具体原因，不再只有一句「没读到历史」。

## 已知限制

- 云端连接的后台通知仍未接入，关闭 App 后只有回到前台才能看到新状态。
- 其他电脑的并行监控只覆盖局域网；云端电脑只列出，需要先切过去。
- 网络很慢时虽然会显示「已缓存 N 条」，但消息正文仍要等连接恢复才画出来。
- 特别长的会话仍然要整段读取，没有分段加载；会话继续变长时可能再次遇到读取缓慢。
